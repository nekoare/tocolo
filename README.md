# Tocolo

Scene でアバターのモデルをクリックすると、その場所のメインテクスチャの一領域の色を、陰影を保ったまま非破壊（NDMF）で変える Unity Editor 拡張です。シーン上のマテリアル・テクスチャ資産は変更せず、プレビューとアップロード時のビルドでだけ色が変わります（アップロードへの反映は有料版）。

## 無料版でできること／有料版で増えること

このパッケージ（`dev.nekoare.click-recolor`）は無料版です。有料版（`dev.nekoare.click-recolor-pro`）を追加で入れると、無料版で作った編集をそのまま引き継いで使えます。

| | 無料版 | 有料版を追加 |
|---|---|---|
| Scene でクリックして範囲を選ぶ・色を変える | ○ | ○ |
| NDMF プレビューで結果を見る | ○ | ○ |
| 編集一覧（有効／無効・名前・選び直し・削除） | ○ | ○ |
| アップロード時に反映 | × | ○ |
| 書き出し（メインテクスチャ／lilToon の 2nd／マスク） | × | ○ |

- 無料版では、アップロードしても色は変わりません（元の色のままアップロードされます。アップロード自体は失敗しません）。編集のあるアバターでは、NDMF の報告画面に「無料版のためアップロードには反映されません」と表示されます。
- 無料版の Inspector では、書き出し欄の代わりに「書き出しとアップロードへの反映は有料版で使えます」と表示されます。

## 必要なもの

- Unity 2022.3
- VRChat SDK Avatars 3.7.0 以上
- NDMF 1.14.0 以上

## 使い方

1. 次のどれかで Scene 編集を始めます。
   - Scene ビューのツールバーにある色相環アイコンを押す（対象が決まっていなければ、Scene でモデルをクリックするとそのアバターが対象になります）
   - アバターに付けたコンポーネントの Inspector で［Scene で色を変える］を押す
   - Hierarchy でアバターを選び、メニューの Tools > Tocolo > 選択中のアバターに追加 でコンポーネントを付けてから、Inspector の［Scene で色を変える］を押す
2. Scene で色を変えたいところをクリックすると、パネルの「影響範囲」に応じて範囲が選ばれます。
   - パーツ: クリックした場所を含むパーツ（UV のつながった一領域）
   - 同じ色: クリックした場所とつながった、ほぼ同じ色の範囲
   - 似た色: 同じ色より広めのしきい値で選んだ範囲
   - 同じ色／似た色では、パネルの「しきい値」「ぼかし」「範囲」（つながった範囲／パーツの中／テクスチャ全体／アバター全体(重いかも)）で選び方を調整できます。「ゴマ塩除去」で選択範囲の細かいムラ（点状の取りこぼしや飛び地）を減らせます。「はみ出し幅」で選んだ範囲を UV の外側へ少し広げます（縁の色残り防止）。
   - Ctrl＋クリックで、同じ編集に別の点を足したり外したりできます（複数のパーツや離れた同じ色を 1 つの編集にまとめる）。パーツモードでは Ctrl＋ドラッグの矩形で、矩形に入るパーツをまとめて足せます。
   - 「マテリアルをまたいで選ぶ」を ON にすると、Ctrl＋クリック・矩形で別のマテリアル（別のテクスチャ）の点も同じ編集に連結できます。連結した編集は色や設定を共有します。
   - 点が複数のとき（または連結のとき）は「各点の色を揃える」が出ます。ON にすると点ごとに明るさの分布を取ってそれぞれを目標の色に揃え、OFF では全体で 1 つの分布を取るので点どうしの明るさの差が保たれます。
   - 「範囲を表示」を ON にすると、いま選んでいる編集の範囲が Scene に縞模様で重ねて表示されます（プレビューだけで、アップロードには影響しません）。
3. パネルのカラーホイール（HSV／RGB のスライダーに切り替え可）で「色 1」を選びます。カラーコードの入力や、最近使った 5 色からも選べます。ホイール左上のスポイトを押してから Scene のモデルをクリックすると、その場所の元の色を取れます（Esc でやめる）。結果は NDMF のプレビューで Scene にすぐ映ります。
   - 「陰影の暗さ」で影の暗さを、「不透明度」で色変えの効き具合を調整できます。「陰影の暗さを自動調整」で色 1 に合った値に戻せます。
   - 「陰影の強調」は、元の陰影の幅が狭い部分（真っ白・真っ黒に近い髪など）で、目標の明るさ範囲いっぱいに陰影を広げます。「各点の色を揃える」と組み合わせると複数のパーツを同じトーンに揃えられます。
   - 「元の色」の見本か「リセット」を押すと、色の指定を取り消して元の色に戻せます。範囲や陰影の設定はそのまま残りますが、色未設定の状態に戻るので、色を選ばずに別の場所をクリックするとこの編集は消えます。
4. 「グラデーション」を ON にすると Scene に箱が出て、箱の下端の「色 1」から上端の「色 2」へ色が変化します。箱を動かして向きと範囲を決めてください。
   - 色 2 は、グラデーション欄の「色 2」を選ぶと、上の見本行・カラーホイール・陰影の暗さ・不透明度が色 2 のものになります（陰影の強調は色 1 と共通）。
   - 「箱の中だけ」を ON にすると、グラデーション方向で箱の外にある部分は元の色のままになります（横方向は切りません）。
   - 色を変えたくないパーツ（同じテクスチャを使う別の Renderer など）は、「範囲」の上の「除外リスト」から Hierarchy の GameObject をドロップして除外できます。除外した Renderer はプレビュー・アップロード・書き出しのどれでも元のマテリアルのままで、Scene でクリックしても選ばれません（Inspector の「除外する Renderer」でも編集できます）。
5. 続けて別の場所をクリックすると、新しい編集になります。色を決めた編集の範囲をもう一度クリックすると、その編集を選び直して色や設定を変えられます。その範囲に重ねて新しい編集を作りたいときは Shift＋クリックします。
6. 有料版を入れていれば、アバターをアップロードすると、ビルド時に生成したテクスチャ・マテリアルへ差し替えて反映されます。元のテクスチャ・マテリアルは変更しません。無料版ではアップロードに反映されません。

Esc か Inspector の［Scene 編集を終了］で Scene 編集を抜けます。

### 編集一覧

コンポーネントの Inspector の「編集一覧」に、クリックで作った編集が並びます。各行のチェックで有効／無効を切り替え、名前を付け、［Scene で選ぶ］でその編集を Scene 編集で選び直せます。［すべて削除］で全部消せます。「プレビュー解像度」を下げるとプレビューの反応が軽くなります（アップロード時は元の解像度で処理します）。

### 書き出し（有料版）

書き出し（メインテクスチャに焼き込み／lilToon の 2nd テクスチャに焼き込み／マスクだけ書き出し）は有料版の機能です。使い方は有料版の README を見てください。

## 対応しているもの

- メインテクスチャのプロパティ: `_MainTex` / `_BaseMap` / `_BaseColorMap`

## 注意

- 非破壊です。シーン上のマテリアル・テクスチャ資産は書き換えません。
- Play モード中は使えません。
- Prefab の編集モード（Prefab を開いて単体で編集している状態）ではプレビューされません。シーンに置いたアバターで使ってください（NDMF のプレビューが Prefab 編集モードに対応していないため）。
- シーンに置いたアバターで使ってください。Project にある Prefab 資産では動きません。
- メッシュのインポート設定で Read/Write を有効にしておくことを推奨します。無効だと選択範囲を作れず、その編集はプレビュー・ビルドに反映されません。
- **他のテクスチャ加工ツールとの併用**: 本ツールはアップロード時の処理を他のテクスチャ加工ツール（キメラヘアマスターなど）より**先**に行います。そのため、同時に NDMF で処理すると本ツールの結果の上に他ツールの加工（髪の色合わせなど）が掛かります。他ツールの結果の上に色を載せたい場合は、**先にそのツールでエクスポート（テクスチャとマテリアルを確定）してから**、本ツールで色を変えてください。

## 既知の制限

- アップロード時の警告（種の Renderer が消えた等）は NDMF の報告窓に出ます。プレビュー中の警告は Console に出ます。
- 1 枚のテクスチャに 17 件以上の編集があると、スライダー操作のたびに一部のマスクを作り直すため反応が落ちます。
- アニメーションや他ツールのマテリアル差し替え機能で切り替えられるマテリアルは対象外です（Renderer に最初から割り当てられているマテリアルだけを見ます）。切り替え先のマテリアルには色変えが載りません。
